# Henry - AI Engineering

Repositorio de cursada del bootcamp de AI Engineering en Henry (LangChain, RAG, agentes, MCP).

## Estructura

```
henry-ai-engineering/
├── modulo-1/       # Ejercicios y proyectos del Módulo 1
├── notebooks/       # Jupyter notebooks (si aplica)
└── README.md
```

Cada módulo nuevo se agrega como su propia carpeta (`modulo-2`, `modulo-3`, ...) a medida que avanza la cursada.

## Cómo correr el proyecto

_Completar con instrucciones de instalación/ejecución a medida que el módulo lo requiera (por ejemplo `pip install -r requirements.txt` o `npm install`)._
